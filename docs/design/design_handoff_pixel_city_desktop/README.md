# Handoff: Pixel City Desktop — 광화문 픽셀 지도 (데스크톱 웹)

## Overview
모바일 프로토타입(`design_handoff_pixel_city/`)의 데스크톱 버전. 방식은 **"지도 전체 + 떠 있는 창들"** — 사이드바 없이 지도가 화면 전체를 차지하고, AI 가이드·피드·도감·명소·올리기·엽서가 각각 **드래그 가능한 플로팅 윈도우**로 지도 위에 뜬다. Isopolis처럼 지도 몰입을 우선하되, 창을 여러 개 동시에 열어 채팅 → 루트 → 명소 상세를 나란히 볼 수 있다.

데이터 모델(SPOTS·ROUTES·FEED·응답 규칙)과 컬러/타이포 토큰은 모바일 핸드오프와 동일. 이 문서는 **데스크톱에서 달라지는 것**을 중심으로 기술한다.

## About the Design Files
HTML 파일은 디자인 레퍼런스(프로토타입)이며 그대로 배포하는 코드가 아니다. 대상 코드베이스(React + Canvas 타일 뷰어 권장)에서 재구현할 것. 창 관리(z-order, 드래그, 화면 클램프)는 `source/Pixel City Desktop.dc.html`의 로직 클래스가 기준.

## Fidelity
High-fidelity. 플레이스홀더: 사진(그라디언트), 카드 아트(그라디언트), 지도(1536² 정지 이미지 1장 → 실제는 `web/tiles` 피라미드), LLM 응답(정규식 3종), 아이콘(텍스트 글리프 ◎ ▤ ◫ ✕ ↑ ♥ ▶ ✉ ☂).

## Layout (1440×900 기준)
```
┌ 툴바 (top 18, 좌우 20) ──────────────────────────────────────────┐
│ [로고 pill] [AI 검색 flex 1 1 220 / max 560] [레이어 칩×4]  … [낮|노을|밤] [☂ 비] [HY] │
│                                                                   │
│ [독]   ┌ 창 (x 96, y 84+) ┐          ┌ 명소 창 (우측 정렬) ┐        │
│ AI     │                   │          │                    │        │
│ 피드   │                   │          │                    │  [+]   │
│ 도감   │                   │          │                    │  [−]   │
│ 올리기 └───────────────────┘          └────────────────────┘ [미니맵]│
│                     [루트 바 bottom 24, 중앙]                       │
└───────────────────────────────────────────────────────────────────┘
```
- **지도**: `position:absolute; inset:0`. 배경 #D9CBA5. 초기 scale 0.8, 경복궁(520,640) 중앙 정렬.
- **툴바**: `flex-wrap:wrap; row-gap 8` — 1180px 미만에서 두 줄로 접힘(우측 그룹이 아래로). 이때 `topH`가 64→110으로 바뀌고 독·창 y 시작점이 따라 내려간다.
  - 로고 pill: #3A2A1E, `border 3px`, radius 10, `shadow 4px 4px 0 #2E1C10`. 26px 노란 사각(#F2C14E, inset 섀도) + "PIXEL CITY"(NeoDunggeunmo 16) + 구분선 + "광화문 · 경복궁" 13px 70%. 모두 nowrap.
  - AI 검색: 높이 46, `rgba(251,243,228,.94)` + blur, `border 2px #3A2A1E`, radius 10, `shadow 4px 4px 0`. 좌 24px "AI" 배지(#E8735A), 우 `↵` 힌트. Enter → 질문 전송 + 가이드 창 열림/포커스.
  - 레이어 칩: padding 8 12, radius 8, `border 2px`, `shadow 3px 3px 0`. 켜짐 #3A2A1E/#FBF3E4.
  - 시간대 세그먼트: #FBF3E4 트랙(padding 3) 안에 [색견본 10px + 라벨] 3개, 활성 #3A2A1E. ☂ 비 토글 버튼. HY 아바타 38×38 #8CC5D8.
- **독(좌측)**: left 20, top `topH+20`. 56×56 버튼 4개(AI 가이드 / ▤ 피드 / ◫ 도감 / + 올리기), `border 3px`, radius 10, `shadow 4px 4px 0`. 열린 창의 버튼은 눌린 상태(#3A2A1E 배경, `translate(2,2)`, 그림자 2px). 클릭 = 토글(열기/닫기).
- **줌 + 미니맵(우하단)**: right 20, bottom 24, z-index 3(창 아래). +/− 38×38 스택. 미니맵 180² (vh<700이면 120²), 지도 전체 썸네일 + 시간대 틴트 + 현재 뷰포트 사각(#E8735A 2px, 15% 채움) + 좌상단 `Z 0.80` 배지.

## Floating Windows
공통: `#FBF3E4`, `border 3px #3A2A1E`, radius 12, `popin .2s`. 최상위 창 `shadow 8px 8px 0 #3A2A1E`, 나머지 `5px 5px 0 rgba(58,42,30,.55)`. z-index 10+순서.
- **헤더 40px**: 창별 색 배경 + `border-bottom 3px`. 12px 색 점 · 제목(NeoDunggeunmo 14) · 우측 부제 11px · ✕(22×22 #E8735A, 2px 테두리). 헤더 pointerdown → 드래그(전역 pointermove/up 리스너), 클램프 x∈[0, vw−w], y∈[topH+8, vh−260].
- **크기 클램프**: `w = min(def.w, vw−40)`, `h = min(def.h, vh−y−16)`. 내용 영역은 `flex:1; overflow-y:auto`(스크롤바 6px #C9B58E) — 작은 화면에서도 입력 바가 항상 보인다.
- **기본 위치**: 대부분 x 96(독 옆). 명소·엽서 창은 우측 정렬 `x = vw − w − 20`(1200px 미만에서는 미니맵과 겹치지 않게 210/150px 더 왼쪽).
- **Esc** → 최상위 창 닫기. 창 클릭 → 최상위로.

## Map Interactions (데스크톱 전용)
- **팬**: 좌클릭 드래그. 커서 grab/grabbing.
- **휠 줌**: 커서 위치 기준 확대(×1.12/스텝), scale ∈ [0.35, 2.2]. +/− 버튼은 화면 중심 기준 ×1.25.
- **핀 호버**: 해당 핀 `scale(1.08)` + z 상승, 나머지 핀 opacity .55. 루트가 없을 때 핀 위에 **미리보기 카드**(220px, 90px 사진 + 이름 18px + "♥ 1240 · 사진 38장 · 궁궐") — pointer-events none.
- **양방향 하이라이트**: 피드 카드·도감 카드·추천 코스 경유지 행에 호버 → 지도의 해당 핀 강조(같은 `hover` 상태 공유). 경유지 행 배경 #F7E9C6 → 호버 #F2C14E. 경유지 행 클릭 → 카메라 이동.
- **루트 바(하단 중앙)**: #3A2A1E, `shadow 5px 5px 0 #2E1C10`. 제목(픽셀 14) + 메타 · **경유지 번호 버튼 4개**(30×30, `border 2px #F2C14E`, 현재 = 채움) 클릭 시 해당 경유지로 점프 · "다음 →" · ✕.
- **올리기 — 명소 모드**: 지도 커서 crosshair, 클릭 → "새 장소" 임시 핀(#E8735A, dashed 테두리, bob 애니메이션), 재클릭 시 이동. 드래그(4px 이상 이동)와 클릭 구분.
- **올리기 — 루트 모드**: 기존 핀 클릭 → 경유지 추가(명소 창은 열리지 않음), 지도에 주황 점선(`#E8735A 8px dasharray 6 14`)으로 미리보기. 2곳 미만 제출 시 토스트.
- **토스트**: top 88 중앙, #3A2A1E + `border 2px #F2C14E`, `shadow 4px 4px 0 #2E1C10`, 1.8s.
- **카드 획득 모달**: 전체 딤 `rgba(58,42,30,.7)`, 카드 220px, 클릭으로 닫기. (모달은 이 화면과 창 위 z 50.)

## State (모바일 대비 추가분)
```
vw, vh                       // resize 리스너로 갱신 → 클램프 계산
wins: { [key]: {open, x, y} }   // key ∈ chat|feed|book|spot|upload|post
order: string[]              // z-order (마지막 = 최상위)
scale 0.35–2.2, pan
hover: spotId|null           // 핀·리스트 양방향 하이라이트
draftPin {x,y} | routeDraft[] // 올리기 모드
feedFilter: 'all'|'route'|'spot'
time, rain                   // 툴바에서 직접 토글 (prop 아님)
```
`topH = vw < 1180 ? 110 : 64` — 툴바 줄바꿈 높이. 독 top = topH+20, 창 y 최소 = topH+8.

## Responsive
- ≥1440: 툴바 한 줄, 창 기본 크기 그대로, 명소/엽서 창은 우측 20px에 정렬.
- 1180–1440: 툴바 한 줄 유지(검색 필드 축소), 명소 창은 미니맵 왼쪽으로.
- <1180: 툴바 두 줄, 모든 창 높이 = vh − y − 16, 미니맵 120². (프로토타입은 924×540까지 확인.)
- <900: 이 레이아웃 비권장 → 모바일 프로토타입으로 전환.
