## 원본과 생성

VWorld 자료만 사용했다. 두 장소 모두 지붕/석축/출입구 또는 상부/빈 공간/지지 구조를 확인하여
외부 사진 추가 없이 시험 입력으로 승인했다. 이는 실제 복원 정확도나 사용자 미감 승인이 아니다.

- 광화문 촬영: `20260914T143347349166Z/gwanghwamun`
- 종로타워 촬영: `20260914T143527940806Z/jongno-tower`
- 정사영1024²·화면폭800m·방위각22.5°·내려다보기30°, 앞/중간/뒤100m 기준선 모두128px.
- 3D 캐시 사전 로딩의 원근 화면은 입력으로 저장하지 않았다. 지형 로딩 완료를 외관 완전성 판정으로 사용하지 않았다.
- 기존 P2 스냅샷 높이가 P1과 달라, 새 원본의 실루엣·접지점에 기준을 두었다. P1과 기존 스냅샷을 수정하지 않았다.

배경과 독립 외형을 따로 생성했다. 기존 그림에서 랜드마크를 잘라낸 방식이 아니다.
`imagegen` 스킬의 참고 이미지 역할 구분과 시점/구조 보존 지침을 프롬프트에 적용했고,
실행은 사용자 승인대로 기존 OpenRouter `openai/gpt-image-2.5-sunburst` / OpenAI 제공업체·high·1:1을 유지했다.

| 요청 | 횟수 |
|---|---:|
| 광화문 배경·독립 외형·외형 보정 | 3 |
| 종로타워 배경·독립 외형 | 2 |
| 합계 | **5 / 최대6** |

실제 비용 **$0.408161**, API 실행시간 합계 **249.476초**. 준비·개발·검수 시간은 별도다.
종로타워 보정1회는 생략하고 생성을 닫았다. 광화문으로 예산을 옮기거나 재시도하지 않았다.
지도 조작 중에는 AI 요청을 하지 않는다. 키는 환경변수·임시 메모리 응답으로만 사용한다.

종로타워 배율은 생성 원출력의 알파 경계와 원본 폭을 비교해 맞춘 값이다. AI가 요청한 프레이밍을
그대로 지켰다는 뜻이 아니다. 가로/세로 동일 배율만 사용했고 비균등 늘이기·회전은 하지 않았다.
원출력은 보존하며 실제 투명도를 유지한다. 배경 RGB에 보이는 색이나 광택을 알파와 혼동하지 않는다.

종로타워의 원본 빈 공간 주석과 겹치는 출력 불투명 픽셀은255개로, **빈 공간 전체의 위치 정합은 미통과**다.
보행 가림과 클릭에는 실제 외형 알파에서 만든 마스크를 사용한다. 외형의 빈 공간을 검사에 맞춰 임의로 뚫지 않았다.
초기 클릭 검수점(510,480)은 생성된 상부 보에 걸려 실패했고, 실제 빈 공간 내부(513,487)로 검수점을 바로잡았다.
이는 전체 원본-출력 정합 통과와 구분한다.

두 배경은 도로2점·인접 건물 너비1개의 생성 전 주석을 보존했으나, 생성 후 확실한 대응을 측정하지 못해
누락으로 기록했다. 도로8px/너비±15% 검증은 **미통과**다. 주변 배경의 변화, 복원된 숨은 공간과
부드러운 그림자도 AI 재해석이다. 동적 일조·적설에 바로 쓸 수 있는 정합 완료 자료로 간주하지 않는다.
