## 현재 실행 범위 — Qwen 로컬 단일 구역 화풍 시험

최신 결정: 기존 BF16 실행을 중단하고 GGUF Q8_0·Diffusers·MPS를 시험한다.
약 38.62GB 활성 파일 세트(기존 캐시 보존), 512px 4단계 smoke 뒤 1024px 40단계
seed 20260913 한 장만 생성한다. 반복 재현은 생략한다. `--variant q8`로 실행하며
상태/산출물은 `eval/vworld/qwen/q8/runs/`에 분리한다. 아래 두 seed/반복은 BF16 이력이다.

실측 상태: 다운로드·해시 검증 완료, 추가 빈 보조 텐서 `__index_timestep_zero__`로
키 검사가 실패하여 로딩 전에 중단했다. smoke와 후보 생성은 미실행이다.
후속 구현: ComfyUI의 2511 식별용 빈 F32 표식만 검증 후 메모리에서 제외한다.
나머지 키/형태와 Q8 압축 유지 검사는 계속 엄격하게 수행한다. 원본 GGUF는 수정하지 않는다.
루트 `docs/design`은 모바일 가독성 검수 기준으로만 사용한다. AI 입력과 덕수궁 구역은 유지하며
앱 UI는 구현하지 않는다. smoke 뒤 후보 한 장을 생성하고 구조·미감·390px 가독성을 별도 판정한다.

사용자가 기존 RPG 시안 대신 선명한 게임 픽셀 표현을 요청했다. 현재 원근 시점과 건물 배치·
큰 형태·도로 연결은 유지하되 실제 지도에서 보이는 외관 특징을 픽셀 그래픽으로 재해석한다.
아래의 기존 SDXL 추천/체크박스는 이 결정을 대체하지 않으며 과거 구현 이력으로만 남긴다.

- 고정 리비전 Qwen-Image-Edit-2511을 기존 Diffusers·MPS·BF16으로 실행한다.
- `qwen-prepare`에서만 모델을 다운로드하고 `qwen-pilot`은 입력 해시를 검증해 오프라인 실행한다.
- 도심 원본의 768px 정사각형 구역과 사용자 스타일 참고를 역할별로 전달한다.
- 512px·4단계 smoke → 1024px·40단계 두 seed → 첫 seed 반복 순서다.
- 원출력, 2px 격자 정리본, 동일 원본 범위의 보정된 과거 시안, 중첩 검수 화면을 분리 보존한다.
- 출력 형태·유한값·격자·재현성은 자동 검사하고 미감/개별 구조는 별도 육안 판정한다.
- 실행 오류나 메모리 부족은 실패 기록으로 남긴다. 메모리 보호 해제·외부 GPU 전환은 금지한다.
- 사용자 시각 승인 전에는 LoRA·다중 타일·전체 지도 생성·메인 병합으로 확대하지 않는다.

## 검증 기준

- 원래 건물·도로·클래스 마스크를 기본 렌더와 픽셀 단위 비교한다.
- 처마/그림자 확장은 12 화면px(4 아트픽셀) 이내다. 기본 구조 마스크에는 쓰지 않는다.
- 인접 타일 overlap 불일치 0.5% 이하, 결과 색상은 설정된 48색 내에 있어야 한다.
- 같은 설정으로 시안을 두 번 렌더해 이미지 바이트가 같은지 확인한다.
- 이전 결과와 비배경 픽셀의 60% 이상에서 RGB 채널 중 최대 차이가 18 이상이어야 한다.
  이 수치는 변화량만 확인하며 미감 통과 판정을 대신하지 않는다.
- 비교표의 기본 렌더는 고정 데이터 기반이며 prototype1 최신 뷰어 캡처가 아니다.
- 자동 테스트는 기하 골든 좌표·전역 패턴·승인 대기·웹 인터랙션 계약을 확인한다.
  실제 브라우저 시각 QA와 구분해 보고한다.

## 승인 후 실행

사용자가 시안을 승인한 뒤 담당 에이전트가 `eval/diorama/approval.json`에
`approved_by: "user"`, 승인한 report의 `signature`, report 파일 SHA-256을
`report_sha256`으로 기록한다. 승인을 받기 전 이 기록을 만들지 않는다.
이 파일은 우발적인 전체 생성을 막는 작업 게이트이며 보안 인증 수단은 아니다.
설정·에셋·렌더러·시안을 바꾸면 다시 시안을 생성하고 검수해야 한다.

```bash
prototype2/.venv/bin/python prototype2/scripts/diorama_map.py build --all
prototype2/.venv/bin/python prototype2/scripts/diorama_map.py validate --all
prototype2/.venv/bin/python prototype2/scripts/diorama_map.py assemble
prototype2/.venv/bin/python prototype2/scripts/diorama_map.py pyramid
```

새 모자이크는 `work/diorama/`, 새 웹 타일은 `web/tiles/diorama/`에 생성한다.
완료 후 웹 매니페스트에 baseline/diorama 스타일과 기본값 diorama를 기록한다.
이전 타일과 모자이크는 보존하며 기존 매니페스트도 뷰어에서 계속 지원한다.

VWorld 시험은 기존 전체 디오라마 승인과 별도다. 각 지역이 외관 확보율 70%, 중앙 정렬
2px, 95백분위 5px 기준을 통과해야 로컬 AI가 실행된다. AI 결과는 건물 마스크 내부만
교체하고 지역별 외관 서명 고유 비율 80% 이상이어야 한다. 직교 카메라 또는 정합 기준이
실패하면 VWorld 화면을 전체 지도 타일로 확장하지 않는다.

해당 시험에서 직교 카메라 설정은 VWorld 내부 렌더 오류를 냈다. 모든 직교 설정이
불가능하다고 입증한 것은 아니다. 과거 정합 5~13.9px 표기는 전역 이동 추정치이며 정합
잔차의 중앙값/95백분위가 아니다. “외관 확보율 90.9~99.3%” 역시 정합하지 않은 기존
마스크에서 RGB 대비를 측정한 대리 지표로, 실제 텍스처 확보율을 뜻하지 않는다.
`regional_reference_fallback`은 색·재료 분포를 ID에 재배치한 해석이며 개별 외관 복제가 아니다.

사용자 피드백으로 마스크 재투영 결과는 최종 후보에서 제외했다. 덕수궁·시청 주변 원근
장면의 2px·64색 Direct 후보는 경계 재현율 87.1~88.5%와 전역 이동 추정 0px를 기록했다.
이는 개별 건물·도로의 구조 보존 판정이 아니며, 과거 추천 0.35도 사용자 승인이 아니다.

생활형 픽셀 RPG 후보는 미감 미승인으로 현재 후보에서 제외한다. 384px 축소·중간값 필터·
48색 제한이 세부를 뭉갰으며 경계 재현율 70.8~74.9%는 원본 경계를 덧그린 후의 수치다.
강도 0.60의 동일 seed 반복 결과 일치는 별도 실측이다. 장식 레이어 외에도 AI 원출력에
장식이 포함될 수 있어 “장식물은 투명 레이어에만 존재”라는 이전 설명을 정정한다.
