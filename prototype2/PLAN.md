## 진행 현황 — 2026-09-04 기준

> 상세 기록은 [CHANGELOG.md](CHANGELOG.md). 여기는 "어디까지 됐고 뭐가 남았는가"만 본다.

### 끝난 것

| | 산출물 | 비고 |
|---|---|---|
| ✅ P2-0 기준선 | `inputs/source/base_rgb.png` + `camera.json` | `prototype1/poc/gyeongbok.png`와 동일 범위 |
| ✅ P2-1 조건 이미지 | `edge` / `height` / `mask` | 은면 제거된 라인아트. ControlNet 바로 입력 가능 |
| ✅ 실행 환경 | `prototype2/.venv` + SDXL·ControlNet 캐시 | Mac MPS, 장당 30~90초 |
| ✅ 판정 도구 | `scripts/overlay.py` | 라인 중첩 + retention 점수 |
| 🟡 S1 1차 | 결과 15장 + 대조 시트 2장 | **판정 미완 — 시간 때문에 중단** |

### 남은 것 — 다음 세션은 여기서 시작한다

1. **S1 마지막 조정: txt2img + ControlNet** ← 최우선. 구현은 끝났고 실행만 남았다

   ```bash
   prototype2/.venv/bin/python prototype2/scripts/s1_edit.py \
     --inputs prototype2/inputs_zoom --tag _t2i --mode txt2img --strengths 0.5,0.8
   prototype2/.venv/bin/python prototype2/scripts/overlay.py
   ```

   img2img는 초기 latent가 평평한 렌더라 모델이 원본 색·면을 못 벗어났다.
   txt2img는 라인아트로 구조만 잡고 색·질감을 처음부터 그리게 한다.

2. **사람의 판정** — 기와지붕·처마가 생겼는가. 이게 §3의 "조정 2회" 중 마지막이다
   - 통과 → S2 (대표 장면 1장 확정) → S3 (좌표 레이어 재결합)
   - 실패 → **§5대로 S1 중단.** prototype1 트랙에 시간을 넣는다
3. (통과 시에만) GPU 대여 → Qwen-Image-Edit로 재생성해 Apache 2.0 서사 복구
4. 미착수: `LICENSES.md`, P2-9 제출 증빙 정리

### 1차 실행에서 확인된 사실

- **구조 보존은 문제가 아니다.** retention 0.74~0.84로 강도와 무관하게 높다
- **미감이 안 올라온다.** 광역(0.9 m/px)에서는 한옥이 17px이라 물리적으로 불가능했고,
  근정전을 150px로 확대해도 **상자가 상자로 남았다** → 축척은 필요조건이지 충분조건이 아니다
- 그래서 다음 변수는 프롬프트가 아니라 **파이프라인 구성(img2img → txt2img)**이다

## 0. 결론부터

README의 P2-0~P2-9는 방향이 맞다. 다만 **D-14에 다 못 한다.** 아래 셋을 미리 잘라낸다.

| README 단계 | 내 판단 | 이유 |
|---|---|---|
| P2-2 모델 후보 2~3종 비교 | **1종으로 시작** | 첫 결과가 나쁘면 2종째도 나쁘다. A가 통과했을 때만 B를 본다 |
| P2-5 인접 2×2 타일 | **계획에서 뺀다** | Isopolis 원저자도 못 푼 문제다([RESEARCH](../prototype1/docs/RESEARCH-isopolis.md)). 여기 걸리면 남은 날이 없다 |
| P2-6 LoRA | **하지 않는다** | 09-09에 판정할 게 아니라 지금 "안 함"으로 못박는다. GPU 학습 + 검수는 D-14에 들어갈 부피가 아니다 |

**대신 목표 산출물을 바꾼다.**

> prototype2의 목표는 **지도 전체를 교체하는 것이 아니라, 제출 문서에 실을 대표 장면
> 1장(경복궁)과 "우리 데이터가 곧 조건 이미지"라는 그림 1장을 확보하는 것**이다.

근거: 제출물은 **한글/PDF 문서**다([prototype1/docs/PLAN.md](../prototype1/docs/PLAN.md)). 심사위원이 보는 것은
이음새 없는 전역 타일이 아니라 문서에 붙은 이미지 몇 장이다. 그러면 README §8의 최종 선택지
중 **2(부분 채택) 또는 3(단일 장면 채택)이 처음부터 현실적인 착지점**이고, 1(전체 채택)은
덤이다. 이렇게 잡으면 타일 이음새 문제가 통째로 사라진다.

기존 뷰어는 그대로 둔다. 정확한 좌표 렌더가 "정확성 15점"을 받는 본체이고,
prototype2 결과는 "혁신성·독창성 30점"을 받는 첨부다. **둘은 경쟁 관계가 아니다.**

## 1. 실행 환경 — 싼 판정을 먼저, 대여는 통과한 뒤에 (09-04 수정)

처음엔 GPU 대여를 선행 조건으로 봤다. **바꿨다.** S1이 답해야 할 질문은 하나뿐이고,
그 질문은 훨씬 싼 모델로도 답이 나온다.

> **도로가 살아 있으면서 디테일이 늘었는가?**

여기서 "아니오"가 나오면 어떤 모델을 빌려도 결과가 크게 달라지지 않는다.
그러면 **대여 자체가 불필요하다.** 그래서 순서를 뒤집는다.

| 단계 | 모델 | 환경 | 비용 |
|---|---|---|---|
| **S1 판정** | SDXL 1.0 + ControlNet-canny | **로컬 Mac MPS** (`prototype2/.venv`) | **0** |
| S2 이후 채택 시 | Qwen-Image-Edit-2511 | Modal/RunPod 대여 | $10~20 |

- Qwen-Image-Edit-2511은 20B / bf16 가중치만 ~40GB라 로컬로는 못 돌린다.
  [CONCEPT §8-B](../prototype1/docs/CONCEPT.md)가 폐쇄 API를 이미 배제했으므로 대여가 유일한 경로다.
- **SDXL은 CreativeML Open RAIL++-M**이라 "전 과정 Apache 2.0" 서사에 안 맞는다.
  LoRA 학습을 하지 않으므로 출력물 이용 자체엔 문제가 없지만, **채택 시 Qwen으로 재생성해
  라이선스 서사를 되돌린다.** S1 결과물은 판정 근거로만 쓴다.

## 2. 이미 끝난 것 — P2-0 / P2-1

09-04 이번 세션에서 처리했다. **API 키도, 원본 WFS 캐시도 필요 없다.**
`prototype1/web/data/*.json`(이미 저장소에 있음)만 읽어서 네 장을 같은 카메라로 그린다.

```bash
/opt/anaconda3/bin/python prototype2/scripts/conditions.py          # 기본: 경복궁 1024²
/opt/anaconda3/bin/python prototype2/scripts/conditions.py --check  # 투영 골든값 대조만
```

| 산출물 | 용도 |
|---|---|
| `inputs/source/base_rgb.png` | 기준선. img2img 입력 |
| `inputs/source/camera.json` | 배율·오프셋·방위·고도. **P2-7에서 POI를 다시 얹을 때 이게 있어야 한다** |
| `inputs/conditions/edge.png` | 은면 제거된 흰 선 → ControlNet lineart / canny |
| `inputs/conditions/height.png` | 높이 명암 → ControlNet depth |
| `inputs/conditions/mask.png` | 클래스 단색 ID → 궁궐/한옥/상업/주거/문교사회/도로/공원/물 |

- 기준 구간: `126.9740,37.5760,126.9820,37.5820` (경복궁~삼청동, 약 700×670m).
  `prototype1/poc/gyeongbok.png`와 같은 범위라 **기존 렌더와 바로 나란히 놓을 수 있다.**
- 카메라: 방위 22.5° / 고도 30° / 1024² / 0.899 m/px. `prototype1/poc/style.json`에서 읽으므로
  기존 렌더러와 절대 어긋나지 않는다.
- 투영은 `prototype1/poc/iso2.py`를 import 한다. **렌더러를 세 번째로 복제하지 않았다.**
  `meta.json`의 골든값 5건과 대조하는 자체 검사가 매 실행마다 돈다.

## 3. 앞으로 할 것 — 3단계로 줄인 순서

### S1. 단일 컷 판정 — **반나절. 여기서 전부 갈린다** (로컬, 09-04 착수)

README P2-2+P2-3을 하나로 합친다. 모델 1종, 조건 1조합, 강도 3단계 × seed 3개 = **9장**.

- 모델: **SDXL 1.0 + ControlNet-canny** — 로컬 무료. 통과하면 Qwen으로 재생성 (§1)
- 구성: **img2img**. `base_rgb.png`가 초기 이미지(구도·건물 위치를 붙잡음),
  `edge.png`가 ControlNet 조건(도로선을 한 번 더 붙잡음). **구조를 두 겹으로 묶는다**
- 실행: `prototype2/.venv/bin/python prototype2/scripts/s1_edit.py`
  설정은 `configs/s1.json` — 프롬프트를 고칠 때 코드를 건드리지 않는다
- 판정: `scripts/overlay.py` — 원본 라인아트 중첩 + retention 점수
- 프롬프트에 반드시 넣을 것: 아이소메트릭 유지 / 도로·건물 배치 변경 금지 /
  제한 팔레트 / 기와지붕·창문·수목·보행자 디테일 추가
- 금지 프롬프트: 원근 시점, 사진풍, 텍스트·워터마크, 새 대형 건물

**판정은 하나만 본다.** 미감 점수가 아니라:

> **도로가 살아 있으면서 디테일이 늘었는가?**

- 예 → S2
- 도로는 살았는데 밋밋 → 프롬프트/팔레트 **1회만** 조정 후 재판정
- 도로가 무너짐 → 조건 강도 올려 **1회만** 재시도
- 두 번 조정해도 안 되면 **여기서 중단.** 후보 B로 넘어가지 않는다

> 후보를 늘리지 않는 이유: 남는 시간을 prototype1의 Phase 2-A(픽셀 격자 복원)에 쓰는 편이
> 확실히 더 이득이다. 반나절이면 되고 효과가 크다고 prototype1 PLAN에 이미 적혀 있다.

### S2. 대표 장면 1장 확정 — 하루

- 후보 중 사람이 1장 고른다. 프롬프트·seed·강도·모델 커밋을 결과와 같이 저장한다.
- `edge.png`를 결과 위에 반투명 중첩한 검증 이미지를 만든다 → `eval/overlay_*.png`
- 육안 검수 항목: 주요 도로 끊김 / 경복궁 영역 건물 임의 추가·삭제 / 없는 수면
- 실패 사례도 지운다. **문서에 "이런 것도 나왔다"를 쓸 재료다.**

### S3. 좌표 레이어 재결합 — 하루 (README P2-7)

생성 배경은 그림이고, 정보는 원래 좌표를 유지한다. **여기가 심사에서 설명력이 가장 큰 지점이다.**

- `camera.json`으로 `prototype1/web/data/poi.json`을 같은 화면 좌표로 투영
- 생성 이미지 위에 POI·지하철 마커를 얹은 정지 화면 1장
- 문서에 **"배경 = AI 해석 / 마커 = 실측 좌표"**를 명시적으로 갈라 쓴다

여기까지가 prototype2의 완주 지점이다. 남으면 2km²로 넓힌다(README P2-8). 안 남으면 안 넓힌다.

## 4. 일정 — 기존 Phase 2와 겹치는 문제

README §7 일정(09-05~09-15)은 [prototype1/docs/PLAN.md] Phase 2(09-05~09-10, 픽셀 격자·팔레트·
랜드마크 AI 변환)와 **같은 기간·같은 사람**이다. 둘 다 하면 둘 다 못 끝낸다.

| 날짜 | prototype2 | 본 트랙 |
|---|---|---|
| 09-04 | ✔ P2-0/P2-1 완료 · **S1 로컬 착수** | 2-A 픽셀 격자 복원 ✔ |
| 09-05 | S1 판정 마무리 | 2-B 팔레트 제한 |
| 09-06 | 통과 시 S2 / 실패 시 **폐기** | 2-B 팔레트 제한 |
| 09-07 | S3 좌표 재결합 | 2-E 랜드마크 변환 1개 검증 |
| 09-08~ | 여력 있으면 확대 | 2-C/2-D |
| 09-16~17 | **개발 중단, 문서만** | 동일 |

**우선순위 규칙: 09-06에 S1이 통과 못 하면 prototype2를 접고 전량을 본 트랙에 넣는다.**
prototype2는 있으면 좋은 것이고, 돌아가는 뷰어는 없으면 안 되는 것이다.

한편 **2-E(국가유산청 사진 → 픽셀 스프라이트 변환)와 prototype2는 같은 모델·같은 GPU를
쓴다.** GPU를 한 번 빌리면 둘 다 처리한다. 이 점에서 두 트랙은 실제로는 협력 관계다.

## 5. 미리 정해 둔 실패 조건

하나라도 걸리면 그 자리에서 멈춘다. "조금만 더"로 시간을 태우지 않기 위해 적어 둔다.

- S1에서 **조정 2회를 써도** 도로 보존과 미감을 동시에 못 얻는다
- 대표 장면 1장을 고르는 데 생성이 **30장을 넘는다**
- GPU 비용이 **$50을 넘어간다** (예산은 $10~20으로 잡았다)
- 09-08까지 S3에 도달하지 못한다
- 출력물의 이용 권리를 `LICENSES.md`에 한 문단으로 설명할 수 없다

멈추면 README §8의 4번(폐기)이고, 그래도 손해가 없다. **조건 이미지 4종 자체가
"공간데이터를 생성 모델의 입력으로 쓴다"는 그림이라 제출 문서에 그대로 들어간다.**
